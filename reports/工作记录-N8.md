## §2 手写求解器调试链

- **2D 发散 NaN（头号坑）**：Ez 更新把差分先除 dx 又乘 `dt/(ε·dx)` → 放大 1/dx 倍指数发散。修：差分用未除 dx 的节点差（与 H 更新一致），系数 `dt/(ε·dx)`。教训写进模块 docstring。
- **1D 反射时窗错位**：mid=700 硬分割把反射峰划进前窗 → ratio≈0。修：按期望到达时刻开窗（n_inc≈(x_p−x_s)/S+30）。
- **到达时刻公式用反**：`n = 40 + (PROBE−SRC)*S` 应为 `/S`（步数 = 格数/S）。
- **FFT 时窗过窄**：half_width=30 vs 色散脉冲宽 ~60 步 → |r|=0.6；加宽到 70 恢复（half_width=60 在生产脚本够用）。
- **高斯包络测量窗失效**：CW 测量窗在包络衰减为零后才采集（驻波深度 0.88 假象）→ 改连续正弦 + 线性斜坡开启，稳态测包络。
- **节点检测选错区**：`argrelextrema` order=3 误检 + 测量区含源近场 → 收紧到 [SRC+3λ, WALL−1.5λ]，深度改 min/max，抛物线插值定位节点。
- **y 边界 Mur 破坏 y 均匀场**：Mur 公式对 y 均匀场冻结边缘行 → 激发 y 向波污染平面波（FFT 时窗法在加宽窗口后仍 |r|=0.62 的根因）。修：`y_neumann=True`（E[:,0]=E[:,1] 对称条件）用于 02；残留波节填充与 Mur 回波系数 0.212 定量对照，如实记录为边界限制。
- **PEC 双极性脉冲峰比较陷阱**（单测阶段）：反射峰幅可略大于入射峰，`argmax(|rec|)` 抓错峰致 r=0.001；符号比较又被两瓣翻转干扰（r=1.76）。修：时窗 RMS + `corr(inc, −ref)>0.95` 反相判据。

## §4 fdtd 库坑清单（Bragg）

1. **period 传 float 被当秒**：`_handle_time` 对非 int 按秒换算 → 传 `int(round(lam/c/dt))` 步数。
2. **单点 LineSource profile NaN**：`vect.max()=0` 除零 → ≥2 点线源 + `profile=np.ones(ny)*amplitude` 覆盖（保 z 均匀）。
3. **`fd.constants.C` 不存在** → `fd.constants.c`（小写）。
4. **探测器分量**：`det.E` 列表 → array (T,1,3)；驱动分量 E[z] 下标 2（不是 1）。
5. **PML 加错轴**：几何 (1,total,3) 传播沿 y → `grid[:, 0:8, :] = fd.PML()`；源/探测轴同步修正 `grid[0, x, :]`。
6. **Object 铺满覆盖 PML** → 只铺 `grid[0, 8:-8, :]`。
7. **Object「对称化」绕过堆栈（T≡1 的根因）**：库把 `inverse_permittivity[:, :, -1, 2]`（z=−1 行 Ez）重置为背景 → 波从该行绕过介质。修：注册后 `obj.inverse_permittivity = np.ones((Nx,Ny,Nz,3))/eps_obj` 整体重建。修复后带隙 T<0.015、通带 0.7–0.93 物理正确。
8. **带隙 lam_lo/hi 次序颠倒**：λ 升序 → f 降序，`band_edges` 返回 (f_lo,f_hi) 按数组序 → `lam_lo=c0/max(f_lo,f_hi)` 归正；`T_min_in_gap` 空数组 min 报错随之解决。
9. **宽带脉冲波形约定不可靠**（hanning profile 与源谱定义纠缠）→ 改 CW 逐波长扫描稳态幅值比（`pulse=False` 分支）。

## §5 Bragg 结果

- 21 波长（700–1400 nm，35 nm 间隔）CW 扫描 3m19s；带隙 840–1225 nm（T<0.5），中心 1014.4 nm vs 解析 1000 nm（**err 1.440%**），带隙内 T_min=0.0010。
- 中心误差来自 8 层对有限尺寸 + 35 nm 采样量化（带隙边缘落在采样点上）。
- 通带 T 0.79–0.95：端面反射 + PML 残余 + 稳态驻波，非透射定义问题（参考 run 同口径归一）。
